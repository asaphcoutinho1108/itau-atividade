# 📐 Itaú UI Style Guide: Laboratório de Fundamentos Visuais
# 📐 Protótipo Itaú de design e cores

Este repositório reúne a documentação e os componentes de um guia de estilos (Style Guide) focado em formatação e fundamentos visuais, desenvolvido dentro do [Figma](https://figma.com "Figma"). O projeto foi criado como um exercício prático de UX/UI Design, utilizando o ecossistema visual do banco **Itaú** como base para estudar hierarquia de informação, paletas cromáticas, escalas de texto e testes de acessibilidade.

---

## 🧭 Proposta do Projeto

O objetivo central foi aplicar padrões de design de interface de forma escalável e consistente, assegurando harmonia estética e conformidade com boas práticas de usabilidade.

O estudo aprofunda-se em três frentes principais de UI:
1. **Sistemas de Cores:** Divisão funcional entre tons institucionais, neutros e sinalizadores de status.
2. **Arquitetura Tipográfica:** Organização de tamanhos e pesos de fontes para estabelecer um ritmo visual claro.
3. **Validação de Contraste:** Laboratório focado em legibilidade (diretrizes WCAG) sobre fundos com propriedades distintas.

---

## ⚙️ Especificações do Guia de Estilos

### 1. Paleta de Cores
Os tokens de cor foram mapeados por função e organizados por intensidade (variando entre tonalidades mais suaves -1 e variações mais profundas +1):

  **Tons Primários (Laranja):** #CC4200 (Suave), #EC6200 (Base) e #FF8E22 (Saturado).
  **Tons Secundários (Azul):** #509AE9, #2079E3 e #1060DE.
  **Neutros Escuros (Dark):** #403E3E, #262323 (Superfície principal) e #0B0A0A.# itau-atividade
